# Jordi Salvia · Comunicació estratègica i d'incidència

Web de serveis professional. Publicada amb **GitHub Pages** (gratuït, sense servidor).

## Què hi ha

- `index.html` — la web sencera (una sola pàgina amb seccions: inici, per a qui, serveis, mètode, per què jo, modalitats i contacte). Sense dependències externes.
- `.nojekyll` — evita que GitHub processi el lloc amb Jekyll.

## Estat

Prova inicial. Marcat amb `noindex` perquè no sigui indexat mentre és esborrany; es treu quan sigui definitiu.

Pendent: correu i telèfon reals (ara hi ha marcadors `[CORREU]` i `[TELÈFON]`), i decidir el domini propi.
